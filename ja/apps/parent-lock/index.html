PARENT LOCK｜お子さんのAndroidスマホの見守り

お子さんの画面時間が心配ですか？PARENT LOCKなら、スマホ利用の明確なルールを決め、使えるアプリを選び、休息の時間をつくることができます。

Google Playでダウンロード

Androidアプリです。iPhone版はまだありません。

スクリーンショット

Androidのペアレンタルコントロールアプリに必要なこと

スマートフォンは、子どもにたくさんのものを与えます。ゲーム、動画、チャット、勉強、そして絶え間ない通知。ルールがないと、数分がいつのまにか夜まるごとになりがちで、家族の話し合いもすぐ口論になってしまいます。

PARENT LOCKは、毎日の攻防ではなく、シンプルで予測できるルールを望む保護者のためにつくられています。目的はスマホを取り上げることではなく、使い方を話し合って決め、その約束を守るのをアプリが手伝うことです。

PARENT LOCKの主な機能

保護者から最もよく求められる三つのことに焦点を当てています。

  • スマホ利用のルール：お子さんのスマホの使い方に、明確な境界線を設定します。
  • 使えるアプリ：お子さんが開けるアプリを選び、それ以外へのアクセスを管理します。
  • 休息時間：スマホを脇に置く時間を決め、睡眠、宿題、散歩、家族の時間を確保します。
  • より安全なデジタル習慣：一貫したルールが、お子さんが画面と健康的なリズムで付き合う助けになります。

こんな方におすすめ

自分のAndroidスマホを持っている、または家族共用の端末を使っているお子さんの保護者に向いています。子どもの画面時間を、段階的に穏やかに制限したい家庭や、複雑な管理画面より、落ち着いたわかりやすい設定を好む方にぴったりです。

初めてスマホを持たせるときにも役立ちます。最初にルールを決めるほうが、後から習慣を変えるよりずっと簡単です。

PARENT LOCKでAndroidのペアレンタルコントロールを設定するには

  • お子さんが使うスマホに、Google PlayからPARENT LOCKをインストールします。
  • まずお子さんと話しましょう。どんなルールをなぜ導入するのかを説明します。
  • 使えるアプリを選び、それ以外の扱いを決めます。
  • 夜の就寝前や宿題の時間など、家庭の一日に合った休息時間を設定します。
  • ときどきルールを見直し、お子さんの成長に合わせて調整します。

画面時間を制限するためのヒント

ルールは、明確で毎日同じであるときに最もよく機能します。事前に説明し、約束を守り、良い手本になりましょう。子どもは、大人のスマホの使い方もよく見ています。

ご自身のスマホの誘惑を減らしたい場合は、PHONE DETOXを試してみてください。さらにアイデアを知りたい方は、Androidのペアレンタルコントロールのガイドをお読みください。

PARENT LOCKをつくった理由

Nikolay Shcherbakovです。20年以上、瞑想、注意力のテクニック、自己観察を実践してきて、スマホがどれほど強く注意を現実の生活から引き離すかを見てきました。私のアプリは、役立つ考えを、毎日のシンプルな一歩にするためのものです。PARENT LOCKも同じ原則から生まれました。小さくて一貫したルールが、子どもが画面と健康的なバランスを保つ助けになるのです。

よくある質問

Androidスマホでペアレンタルコントロールを設定するには？

お子さんのスマホにGoogle PlayからPARENT LOCKをインストールし、使えるアプリを選んで休息時間を設定します。そのあとルールをお子さんに説明し、時間をかけて調整してください。

お子さんが使えるアプリを選べますか？

はい。PARENT LOCKでは、使えるアプリを選び、お子さんのスマホのアプリへのアクセスを管理できます。

子どもの画面時間を制限するには？

睡眠前や宿題中など、スマホを使わない時間帯に、PARENT LOCKで休息時間を設定します。たまの禁止よりも、一貫したルールのほうが効果的です。

PARENT LOCKはどの端末で使えますか？

PARENT LOCKはAndroidアプリで、Google Playで入手できます。

ペアレンタルコントロールは何歳から始めるべきですか？

お子さんが初めてスマホを持つときが最も始めやすく、最初に決めたルールのほうが守りやすいからです。成長に合わせて緩めていくこともできます。
