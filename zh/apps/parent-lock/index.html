PARENT LOCK——孩子 Android 手机的家长控制

担心孩子盯着屏幕的时间太长？PARENT LOCK 帮你为手机使用设定清晰的规则，决定允许使用哪些应用，并留出休息的空间。

在 Google Play 下载

这是一款 Android 应用，目前暂无 iPhone 版本。

Android 家长控制应用应该做什么

智能手机给孩子带来很多东西：游戏、视频、聊天、功课，还有源源不断的通知。没有任何规则，几分钟很容易变成一整个晚上，而家里谈起这件事，也很快会变成争吵。

PARENT LOCK 是为那些想要简单、可预期的规则而不是天天争执的父母设计的。目的不是把手机拿走，而是约定好怎样使用，再让应用帮你遵守这个约定。

PARENT LOCK 的主要功能

应用专注于家长最常提出的三件事：

  • 手机使用规则——为孩子如何使用手机设定清晰的界限。
  • 允许的应用——选择孩子可以打开哪些应用，并管理对其余应用的访问。
  • 休息时间——设定手机退居次要位置的时间，为睡眠、写作业、散步和家庭时光留出空间。
  • 更安全的数字习惯——一致的规则帮助孩子习惯与屏幕之间更健康的节奏。

适合哪些人

PARENT LOCK 适合孩子已有自己的 Android 手机或使用家庭共用设备的父母。它适合希望循序渐进、温和地限制孩子屏幕时间的家庭，也适合更喜欢平和、清晰的设置而不是复杂控制面板的家庭。

当孩子拿到第一部手机时，它也很有用：一开始就约定规则，比日后再改习惯要容易得多。

如何用 PARENT LOCK 设置 Android 家长控制

  • 在孩子使用的手机上从 Google Play 安装 PARENT LOCK。
  • 先和孩子谈一谈：说明你要引入哪些规则，以及为什么。
  • 选择允许使用的应用，并决定其余应用如何处理。
  • 设置适合你家作息的休息时间——例如睡前的晚上或写作业的时段。
  • 时常回顾这些规则，并随着孩子长大加以调整。

限制屏幕时间的几点建议

规则清晰、每天一致时效果最好。提前向孩子解释，说到做到，并以身作则：孩子也会留意大人是怎么使用手机的。

如果你想减少自己使用手机时的分心，可以试试 PHONE DETOX，也可以阅读我们的指南 Android 家长控制 获取更多想法。

常见问题

如何在 Android 手机上设置家长控制？

在孩子的手机上从 Google Play 安装 PARENT LOCK，选择允许的应用并设置休息时间。然后向孩子解释这些规则，并随时间加以调整。

我可以选择孩子能使用哪些应用吗？

可以。PARENT LOCK 让你选择允许的应用，并管理孩子手机上的应用访问。

如何限制孩子的屏幕时间？

在 PARENT LOCK 中为不该使用手机的时段设置休息时间，例如睡前或写作业期间。一致的规则比偶尔的禁令更有效。

PARENT LOCK 可以在哪些设备上使用？

PARENT LOCK 是一款 Android 应用，可在 Google Play 下载。

应该从几岁开始使用家长控制？

最容易的时机是孩子拿到第一部手机的时候，因为一开始约定的规则更容易遵守。随着孩子长大，你可以放宽这些规则。
