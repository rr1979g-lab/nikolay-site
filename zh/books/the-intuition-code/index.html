The Intuition Code（直觉密码）——如何听见内在信号、信任自己

一本讲如何在实践中培养直觉的书，通过观察、练习和个人经验：如何留意内在信号，把第一感觉与随后的怀疑区分开，并建立自我信任。

购买平台 Litres

俄语版

The Intuition Code 讲什么

你是否曾经无视一种直觉，事后又后悔？直觉往往先开口，但它的声音很快就被推理、恐惧和无休止的“万一”淹没。久而久之，我们不再信任自己，做出的选择也不像是自己的。

The Intuition Code 不把直觉看作神秘的天赋，而是看作可以培养的技能。作者结合自己的经验，建议通过观察和练习来下功夫：学会留意第一个信号、理解它，并检验你的感觉。

如何培养直觉：你将学到什么

  • 如何在怀疑淹没之前，留意到你最初的内在信号。
  • 如何把第一感觉与随后出现的想法和忧虑区分开。
  • 如何通过自我观察和定期练习培养直觉。
  • 如何用自己的经验检验你的感觉。
  • 如何一步步建立自我信任，更有信心地做决定。

练习与实践

这本书的重点是实践。光靠读书无法培养直觉：你需要观察、尝试，并留意结果。因此书中包含可以融入普通一天的练习，帮你逐渐学会更好地听见自己。

为了每天训练，作者还开发了 Intuition Trainer 应用：简短的互动练习，帮你留意第一个信号、检验你的感觉并追踪进步。

这本书适合谁

它适合听不到内心声音、或不敢相信它的人，总在反复怀疑自己的决定、事后又希望当初听从第一印象的人。也适合只是想更了解自己和自己反应的人。

关于作者

Nikolay Shcherbakov 写关于思维、直觉、觉知和个人转变的书。二十多年来，他研究并练习冥想、呼吸法、积极暗示、注意力技巧和自我观察。有一个问题一直吸引着他：我们能学会更清晰地听见直觉吗？用他的话说，The Intuition Code 帮你学会留意第一个内在信号。

常见问题

如何开始培养直觉？

书中建议从观察开始：留意第一个内在信号，并学会把它与随后出现的怀疑区分开。然后用练习来巩固这项技能。

书里有直觉练习吗？

有。直觉是在实践中培养的——通过观察、练习和个人经验。

如何区分直觉和恐惧？

书中的一项关键技能，是把第一感觉与随后的怀疑分开。作者的书 The Right Choice 更深入地探讨了做决定时如何区分恐惧和直觉。

The Intuition Code 有英语版吗？

暂时没有。这本书目前只有俄语版，可在 Litres 购买。

关于作者

Nikolay Shcherbakov 是多本关于直觉、思维、觉知与个人转变的图书作者，也是实用手机应用的开发者。二十多年来，他一直练习冥想、呼吸法、积极暗示和自我观察，并把这些经验变成简单易用的日常工具。
