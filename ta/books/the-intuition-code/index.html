நூல்

The Intuition Code (உள்ளுணர்வின் குறியீடு) — உள் சமிக்ஞைகளைக் கேட்டு உங்களை நம்புவது எப்படி

கவனிப்பு, பயிற்சிகள், தனிப்பட்ட அனுபவம் மூலம் உள்ளுணர்வை நடைமுறையில் வளர்ப்பது பற்றிய நூல்: உள் சமிக்ஞைகளைக் கவனிப்பது, முதல் உணர்வையும் அதைத் தொடரும் சந்தேகங்களையும் பிரித்தறிவது, தன்னம்பிக்கையை வளர்ப்பது எப்படி.

வாங்குங்கள்: Litres

ரஷ்ய மொழிப் பதிப்பு

The Intuition Code எதைப் பற்றியது

ஒரு உள்ளுணர்வை ஒதுக்கித் தள்ளி, பிறகு வருந்திய அனுபவம் உங்களுக்கு உண்டா? உள்ளுணர்வு பெரும்பாலும் முதலில் பேசும்; ஆனால் அதன் குரல் காரணங்களாலும் பயங்களாலும் முடிவில்லாத என்ன ஆகும் என்ற கேள்விகளாலும் விரைவில் அமுங்கிவிடுகிறது. காலப்போக்கில் நம்மை நாமே நம்புவதை நிறுத்திவிட்டு, நம்முடையவை போலத் தோன்றாத தேர்வுகளைச் செய்கிறோம்.

The Intuition Code உள்ளுணர்வை ஒரு மர்மமான வரமாக அல்லாமல், வளர்த்துக்கொள்ளக்கூடிய திறனாகக் கருதுகிறது. தன் சொந்த அனுபவத்தின் அடிப்படையில், கவனிப்பு, பயிற்சிகள் மூலம் அதனுடன் பணியாற்ற ஆசிரியர் பரிந்துரைக்கிறார்: முதல் சமிக்ஞையைக் கவனிக்கவும், புரிந்துகொள்ளவும், உங்கள் உணர்வைச் சரிபார்க்கவும் கற்றுக்கொள்ளுங்கள்.

உள்ளுணர்வை வளர்ப்பது எப்படி: நீங்கள் என்ன கற்றுக்கொள்வீர்கள்

  • சந்தேகம் அமுக்கிவிடும் முன் உங்கள் முதல் உள் சமிக்ஞைகளைக் கவனிப்பது எப்படி.
  • முதல் உணர்வையும் அதைத் தொடரும் எண்ணங்கள், கவலைகளையும் பிரித்தறிவது எப்படி.
  • சுய கவனிப்பு, தொடர்ந்த பயிற்சிகள் மூலம் உள்ளுணர்வை வளர்ப்பது எப்படி.
  • உங்கள் சொந்த அனுபவத்துடன் உங்கள் உணர்வைச் சரிபார்ப்பது எப்படி.
  • படிப்படியாகத் தன்னம்பிக்கையை வளர்த்து, அதிக நம்பிக்கையுடன் முடிவெடுப்பது எப்படி.

பயிற்சிகளும் நடைமுறையும்

நூலின் மையம் நடைமுறை. உள்ளுணர்வைப் பற்றிப் படிப்பதால் மட்டும் அதை வளர்க்க முடியாது: கவனிக்க வேண்டும், முயல வேண்டும், விளைவுகளைக் கவனிக்க வேண்டும். அதனால்தான், உங்களை இன்னும் நன்றாகக் கேட்கப் படிப்படியாகக் கற்றுக்கொள்ள, சாதாரண நாளில் பொருத்தக்கூடிய பயிற்சிகள் இந்த நூலில் உள்ளன.

தினசரிப் பயிற்சிக்காக Intuition Trainer செயலி-யையும் ஆசிரியர் உருவாக்கினார்: முதல் சமிக்ஞையைக் கவனிக்கவும், உங்கள் உணர்வைச் சரிபார்க்கவும், முன்னேற்றத்தைக் கண்காணிக்கவும் உதவும் குறுகிய ஊடாடும் பயிற்சிகள்.

இந்த நூல் யாருக்கு

தங்கள் உள் குரலைக் கேட்க முடியாதவர்களுக்கு, அல்லது அதை நம்பத் துணியாதவர்களுக்கு, தங்கள் முடிவுகளை மீண்டும் மீண்டும் சந்தேகித்து, பின்னர் முதல் எண்ணத்தையே கேட்டிருக்கலாமே என்று நினைப்பவர்களுக்கு இது. தங்களையும் தங்கள் எதிர்வினைகளையும் இன்னும் நன்றாகப் புரிந்துகொள்ள விரும்பும் எவருக்கும் இது ஆர்வமூட்டும்.

ஆசிரியரைப் பற்றி

Nikolay Shcherbakov சிந்தனை, உள்ளுணர்வு, கவனத்துடன் வாழ்தல், தனிப்பட்ட மாற்றம் பற்றிய நூல்களை எழுதுகிறார். 20 ஆண்டுகளுக்கும் மேலாக தியானம், மூச்சுப் பயிற்சி, உறுதிமொழிகள், கவனப் பயிற்சிகள், சுய கவனிப்பு ஆகியவற்றைக் கற்றுப் பயின்று வருகிறார். ஒரு கேள்வி அவரை எப்போதும் ஈர்த்துள்ளது: நம் உள்ளுணர்வை இன்னும் தெளிவாகக் கேட்கக் கற்றுக்கொள்ள முடியுமா? அவர் சொற்களில், முதல் உள் சமிக்ஞையைக் கவனிக்கக் கற்றுக்கொள்ள The Intuition Code உதவுகிறது.

எங்கே வாங்கலாம்

The Intuition Code தற்போது ரஷ்ய மொழியில், «Код интуиции» என்ற தலைப்பில், Litres-இல் கிடைக்கிறது. ஆங்கிலப் பதிப்பு இன்னும் இல்லை. நீங்கள் ஆங்கிலம் படிப்பவராக இருந்தால், Amazon-இல் கிடைக்கும் ஆசிரியரின் Thoughts in Circles நூலிலிருந்து தொடங்கலாம்.

கேள்விகளும் பதில்களும்

என் உள்ளுணர்வை வளர்க்க எப்படித் தொடங்குவது?

கவனிப்பிலிருந்து தொடங்க நூல் பரிந்துரைக்கிறது: முதல் உள் சமிக்ஞையைக் கவனித்து, அதைத் தொடரும் சந்தேகங்களிலிருந்து பிரித்தறியக் கற்றுக்கொள்ளுங்கள். பின்னர் பயிற்சிகளால் அந்தத் திறனை வலுப்படுத்துங்கள்.

நூலில் உள்ளுணர்வுப் பயிற்சிகள் உள்ளனவா?

உள்ளன. உள்ளுணர்வு நடைமுறையில் வளர்கிறது — கவனிப்பு, பயிற்சிகள், தனிப்பட்ட அனுபவம் மூலம்.

உள்ளுணர்வையும் பயத்தையும் எப்படிப் பிரித்தறிவது?

நூலின் முக்கியத் திறன், முதல் உணர்வையும் அதைத் தொடரும் சந்தேகங்களையும் பிரிப்பது. முடிவெடுக்கும்போது பயத்தையும் உள்ளுணர்வையும் பிரித்தறிவதை ஆசிரியரின் The Right Choice நூல் இன்னும் ஆழமாகப் பேசுகிறது.

ஆசிரியரைப் பற்றி

Nikolay Shcherbakov உள்ளுணர்வு, சிந்தனை, கவனத்துடன் வாழ்தல், தனிப்பட்ட மாற்றம் ஆகியவை பற்றிய நூல்களின் ஆசிரியரும், நடைமுறைக்கு உதவும் மொபைல் செயலிகளை உருவாக்குபவரும் ஆவார். 20 ஆண்டுகளுக்கும் மேலாக தியானம், மூச்சுப் பயிற்சிகள், உறுதிமொழிகள், சுய கவனிப்பு ஆகியவற்றைப் பயின்று வரும் அவர், அந்த அனுபவத்தை அன்றாட வாழ்க்கைக்கான எளிய கருவிகளாக மாற்றுகிறார்.
